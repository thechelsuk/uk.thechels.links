# links.thechels.uk -  Linktree clone using Jekyll

1. Fork this repo
1. Setup domain or subdomain in your DNS manager, I use Cloudflare
1. Point A records and AAAA records to GitHub's IP adressesa
1. Change CNAME to match your domain/subdomain
1. Edit _config.yml and update with your links
1. Edit logos, fonts and style etc in assets to suit your needs
1. Profit
